# Portfolio Client

React + TypeScript + Vite frontend for the portfolio website.

## Setup

```bash
npm install
npm run dev
```

## Environment

Create a `.env` file from `.env.example` when the contact endpoint changes:

```bash
VITE_CONTACT_API_URL=https://your-contact-endpoint.vercel.app
```

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```
